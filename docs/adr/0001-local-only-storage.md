# 筆記只存在手機本機，不做雲端同步

這是只有一位使用者、主要在 Android 手機上隨手記錄的個人筆記 APP，所以筆記只存在手機本機：不需要帳號、不需要網路，打開就能寫。我們考慮過用 Supabase、Firebase 這類後端做雲端同步，但登入、同步和離線衝突合併的工作量遠大於目前的需求。資料遺失的風險之後用「匯出成檔案」來處理。以後若要加雲端同步，仍然可以做，但需要另外新增後端、帳號和同步邏輯。

為了到時不必轉換既有資料，每則筆記現在就使用隨機唯一 ID（UUID），並記錄最後修改時間。另外因為有回收桶，刪除一開始就是「標記為已刪除」，不會馬上清掉資料，這一點以後做同步時也用得到。

唯一的例外是**空白筆記**：離開編輯畫面時，沒有任何文字也沒有任何附圖的筆記會直接從資料庫刪除，不標記、也不進回收桶。空白筆記只是按了「＋」卻什麼都沒寫的產物，使用者從來沒有把它當成一則筆記，把它放進回收桶只會讓回收桶塞滿誤觸的空殼。以後做同步時，這種筆記也不需要留下刪除紀錄：它只在這支手機上存在了一下子，還沒寫進任何備份檔，其他裝置不可能有它。
